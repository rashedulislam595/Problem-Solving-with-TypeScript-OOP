# Assignment: Problem Solving with TypeScript & OOP

## Assignment Overview

This repository contains my solutions for the **Problem Solving with TypeScript & OOP** assignment. The assignment covers core TypeScript concepts from Modules 1, 2, and 3, including basic types, optional and rest parameters, readonly tuples, interfaces, type narrowing, generics, Promises, and Object-Oriented Programming (OOP).
